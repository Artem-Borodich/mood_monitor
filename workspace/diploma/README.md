# Рабочие файлы диплома (не основной текст)

Сюда скрипты складывают вспомогательные `.txt` — **не** редактируйте вместо `diploma/Дипломначалоконец.docx`.

| Папка | Назначение |
|-------|------------|
| **`exports/`** | Выгрузки текста из Word (`_diploma_*.txt`) |
| **`reports/`** | Отчёты сравнения, структура, ссылки |
| **`styles/`** | XML стилей для отладки оформления |
| **`logs/`** | Логи запуска скриптов |
| **`imports/`** | Текст, извлечённый из PDF-методичек |
