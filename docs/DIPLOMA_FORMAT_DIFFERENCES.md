# Сравнение оформления: Диплома.docx и пример (Нестерович Диплом)

## Найденные отличия (до правки)

| Элемент | Пример | Ваш диплом (было) |
|--------|--------|-------------------|
| Основной стиль текста | «Документация» | Normal |
| Шрифт основного текста | 14 pt (через стиль), по ширине | Times New Roman 14 pt |
| Интервал | 1,5 (line=360) | 1,0 (одинарный) |
| Абзацный отступ | 1,25 см (firstLine=709) | ~1,25 см |
| Заголовок 1 | слева, без принудительного центра | по центру |
| Подписи рисунков | стиль «Документация», по центру, без курсива | Normal, курсив 14 pt |
| Листинги кода | Courier New, 10 pt | Normal (Web), без единого шрифта |
| Список литературы | без нумерации «1.», формат Author, Title : monogr. | нумерованный список, 8 источников |
| Ссылки в тексте | [1], [2], … (~45 источников) | почти отсутствовали (2 ссылки) |
| Колонтитулы | 3 колонтитула (нумерация) | 1 колонтитул |

## Что сделано скриптом `apply_diploma_format.py`

1. Основной текст (с «Введения» до списка литературы): TNR 14 pt, выравнивание по ширине, отступ 1,25 см, интервал 1,5.
2. Заголовки §1–§3: слева, 14 pt, полужирный, интервалы как в примере.
3. Подписи «Рисунок …», «Листинг …»: по центру (рисунки), без курсива, 14 pt.
4. Блоки кода: Courier New 10 pt, одинарный интервал.
5. Список литературы: 20 источников, висячий отступ 1,25 см, интервал 1,5.
6. Ссылки [N] добавлены в абзацы по ключевым словам (без изменения формулировок).

## Не изменялось (по заданию)

- Титульный лист (абзацы до «Введения»).
- Текст разделов (смысл и формулировки).
- Структура глав и подпунктов.
- Вставленные изображения.

## Рекомендуется вручную в Word

1. **Оглавление** — обновить поля (F9), стили toc 1/toc 2 как в примере.
2. **Нумерация страниц** — скопировать колонтитулы из примера (Вставка → колонтитулы) для основной части.
3. **Проверить ссылки** — при необходимости убрать лишние [N] в абзацах с повторяющимися терминами.
4. **Реферат** — если появится отдельным разделом, оформить по образцу титульного блока примера.
