# Диплом — основной текст

## Главный файл

**`Дипломначалоконец.docx`** — единственный рабочий документ диплома. Редактируйте только его.

## Папки рядом

| Папка | Содержимое |
|-------|------------|
| **`references/`** | PDF-методички и примеры оформления (не ваш текст) |
| **`backups/`** | Автоматические резервные копии `.docx.bak_*` |

## Скрипты

Python-скрипты лежат в **`../scripts/`**. Путь к диплому: `scripts/diploma_paths.py`.

```bash
cd ~/Project/mood_monitor
python3 scripts/apply_diploma_format.py
```

## Временные файлы

Экспорты `.txt`, отчёты сравнения, логи скриптов — в **`../workspace/diploma/`** (не путать с основным `.docx`).
